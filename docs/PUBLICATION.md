# 게시본의 보존 범위

- `provenance/CAPTURE_SOURCES.json`은 최종 v7 수집의 29개 원본 소스·설정 해시다. 각 경로 앞에 `source/`를 붙이면 이 저장소의 동일 바이트 파일이다.
- `source/stage2/integration_20260920_v7/SOURCE_MANIFEST.json`은 서버에서 읽은 원본 manifest다. 게시된 핵심 파일에 맞춰 과거 수집 해시를 다시 계산하거나 바꾸지 않았다.
- `provenance/FILES.json`은 파일별 출처와 게시 해시를 기록한다. 보조 코드도 포함하며, 원본 해시와 게시 해시를 구분한다.
- 운영 참조용 `source/stage2/scripts/stage2_supervisor.py`에서만 서버 공개 IP 두 곳을 문서용 주소 `192.0.2.1`로 치환했다. 이 파일은 핵심 29개 수집 manifest에 포함되지 않는다. 원래 프로세스 소유권·GPU·온도·저장소 검사 로직은 유지한다. 이 게시용 수정본을 서버에 배포하거나 실행하지 않았다.
- README, 토픽 안내, 환경 안내와 검증 도구는 게시를 위해 새로 작성했다. 수집 루프·타임스탬프·원본 점군 처리 코드는 수정하지 않았다.
- 기존 QR-ON과 QR-free 결과의 판정은 소급 변경하지 않는다. 과거 보고서의 실행 상태는 당시의 상태다.

## 제외 항목

원본 rosbag2, raw 센서 바이너리, 대용량 압축본, 영상, Isaac 설치본, 모델·텍스처, 비밀번호, SSH 설정·키, 인증 토큰, 세션별 PID·소켓 파일, 전체 로컬 작업 이력은 게시하지 않는다. 에셋과 외부 라이브러리의 사용 조건은 각각의 제공자를 따른다. 이 저장소는 포함하지 않은 외부 에셋의 재배포 권한을 부여하지 않는다.

## 검증 방법

`python -B tools/verify_snapshot.py`는 29개 핵심 해시, 게시 파일 해시, Python 구문, JSON/XML 및 문서 링크를 검사한다. 표준 라이브러리만 사용한다. 과거 rosbag2 감사를 다시 실행하거나 새로운 Isaac 환경에서의 동작을 증명하는 검사는 아니다.
